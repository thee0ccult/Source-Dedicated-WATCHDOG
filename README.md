This tool is a Power Shell based macros software that Watches Source Engine Dedicated servers.
If a server happens to stop due to DoS, Crash, Update, or Hang up etc the watchdog will automatically restart the server putting it back online.

This program is beta and works very well for Windows Server 2019.
FEATURE LIST

    monitors all set servers in 1 config/servers.ps1 file containing server definition sets

    displays all core current server data including players

    restarts any server systematically that happens to shutdown via various circumstances

    handles full automatic rcon command lines for each server

    allows toggling localhost and remote username and password access live

    allows toggling and handling hardcoded -console overridden server definitions for launching vgui mode on the dime.

    can be launched manually via watchdog.ps1 power shell script and opened via browser with choice of IP:PORT or LOCALHOST:PORT or launched by watchdog.exe

    logs activity in separated log data files for each element that builds softwares functions

    instead of 1 solid script is not a broken down and organized software for windows server 2019

    handles all source engine dedicated servers types

    offers server data api with json and also offers web page iframe integrated live server widgets that pull directly from the watchdog back end as well as a custom widget building panel for each server so it can be applied to any web page essence.
