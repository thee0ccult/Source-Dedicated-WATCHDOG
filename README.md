This tool is a Power Shell based macros software that Watches Source Engine Dedicated servers.
If a server happens to stop due to DoS, Crash, Update, or Hang up etc the watchdog will automatically restart the server putting it back online.

This program is beta and works very well for Windows Server 2019.
